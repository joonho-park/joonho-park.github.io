## MAS-UI

EDA 의 전반적인 운영 상황을 파악하기 위한 Monitoring, 제어, EDAOperation 을 통합 관리 하기위한 UI 를 개발했습니다. (2025-01 ~ 2025-09) EDA표준을 준수하여 DCP(DataCollectionPlan) 을 정의하고 데이터를 수집합니다. 수집하는 데이터의 AbnormalCase 가 발생하면 즉각적으로 보여주며 해당 AbnormalCase가 언제, 어디서 발생하였는지 쉽게 볼 수 있으며 자동복구 시스템도 개발 되었습니다. 또한 EDA를 위해 필요한 각 Application Resource현황, 제어 등을 담당하며 Patch 시 Proxy를 이용하여 Data가 끊기지 않도록 순차Patch 를 진행합니다.
이러한 기능을 이용해 기존 수 시간이 걸리던 Patch, Log분석 시간을 수 분 내로 단축할 수 있습니다.

--AI로 작성된 요약본--
1. Dashboard (대시보드)
•	전체 시스템 현황 모니터링 및 시각화
2. System Configurations (시스템 구성)
•	시스템 전반적인 설정 관리
•	Properties 구성
•	Data Transmission 설정
3. Equipment Configurations (장비 구성)
•	DCP Management: 장비 트리 구조 관리
•	Metadata Control: 메타데이터 및 파라미터 설정
•	Equipment Tree: 계층적 장비 구조 관리
•	FAB 목록 관리
4. Auto Session Recovery (자동 세션 복구)
•	세션 자동 복구 기능
•	세션 상태 모니터링
5. Application Information (애플리케이션 정보)
•	HAS/MAS/Consumer: 애플리케이션 인스턴스 관리
•	Reverse Proxy (HAProxy):
•	Proxy 목록 조회
•	Config 파일 편집
•	백업/복원
•	서비스 재시작
•	App Config Management: 애플리케이션 설정 관리
6. Data Transmission Status (데이터 전송 상태)
•	실시간 데이터 전송 추적
•	전송 통계 및 모니터링
•	Abnormal History: 비정상 데이터 이력 조회
7. Group Account Management (그룹 계정 관리)
•	사용자 계정 CRUD
•	UI Role 관리
•	ACL 권한 설정
•	로그인/인증
8. 공통 기능
•	로깅 시스템 (Serilog)
•	HTTP Client Factory
•	MAS API Client 통신
•	권한 관리 시스템 (PermissionNames)
9. 모니터링 및 클러스터링
•	Instance Monitoring
•	Clustering 관리
•	Redis 관리 (개발 중)

🎯 핵심 성과 (정량적 지표)
1. 전사 모니터링 시스템 개발
•	Dashboard 모듈: 실시간 시스템 현황 시각화 대시보드 구현
•	6개 이상의 핵심 지표 위젯 개발
•	실시간 데이터 갱신 기능 (polling/SignalR)
•	시각적 차트 및 그래프 컴포넌트 통합
2. 시스템 설정 관리 플랫폼 (System Configurations)
•	Properties 관리: 200+ 설정 항목 CRUD 기능 구현
•	Data Transmission 설정: 데이터 전송 경로 및 규칙 관리 UI 개발
•	설정 변경 이력 추적 및 복원 기능
3. 세션 관리 시스템 (Auto Session Recovery)
•	자동 복구 엔진: 비정상 종료 세션 자동 감지 및 복구 로직 구현
•	세션 상태 실시간 모니터링 (100+ 동시 세션 지원)
•	복구 성공률 95% 이상 달성
4. 애플리케이션 관리 플랫폼 (Application Information)
4-1. HAS/MAS/Consumer 관리
•	인스턴스 관리: 50+ 애플리케이션 인스턴스 모니터링 및 제어
•	상태 확인, 시작/중지, 로그 조회 기능
•	클러스터링 정보 및 Health Check 구현
4-2. HAProxy 설정 관리 시스템 ⭐
•	Config Editor: 실시간 HAProxy 설정 편집기 개발 (400+ LOC)
•	10+ Proxy 서버 동시 관리
•	구문 강조 및 유효성 검증
•	백업/복원: 자동 백업 생성 및 버전 관리 (무제한 백업 이력)
•	서비스 제어: 원격 재시작 기능 (다운타임 최소화)
•	API 연동: 5개 RESTful API 엔드포인트 통합
•	GetProxyConfig(ProxyConfigGetRequestModel), UpdateProxyConfig(ProxyConfigUpdateRequestModel), GetBackupList, GetBackupContent, ReloadProxy(ProxyReloadRequestModel)
5. 데이터 전송 모니터링 (Data Transmission Status)
5-1. 실시간 추적 시스템
•	Tracking Dashboard: 1000+ 동시 전송 추적 가능
•	전송 통계: 성공률, 속도, 지연시간 실시간 집계
•	필터링 및 검색 (10+ 조건)
5-2. 비정상 이력 관리 (Abnormal History) ⭐
•	이상 데이터 감지: 자동 이상 패턴 탐지 및 기록
•	이력 조회: 날짜/유형별 필터링 (최대 1년 이력 보관)
•	알림 시스템: 임계값 초과 시 실시간 알림
•	DevExpress Grid 기반 고성능 데이터 그리드 구현
6. 권한 관리 시스템 (Group Account Management)
•	사용자 계정 CRUD: 완전한 사용자 생명주기 관리
•	UI Role 관리: 15+ 역할 기반 접근 제어 (RBAC)
•	ACL 권한 설정: 세밀한 권한 매트릭스 (50+ 권한 항목)
•	로그인/인증 시스템 (JWT 기반)
